# 🥩 Asado Simulator 2 - 3D 模型资产使用声明 (3D Models License)

## 🎨 关于这些模型 (About the Models)
本文件夹中的所有 3D 角色模型（包括 `.bbmodel`， `.glb`， `.fbx` 格式）专为 **Asado Simulator 2** 打造，采用了复古精细的 64x64 8-Bit 像素与 YSM (Yes Steve Model) 二次元高精度比例。

**【制作过程声明】**
这些模型**并非纯 AI 生成**。它们的初始基础几何框架由 AI (Antigravity) 辅助生成，但随后由开发者 (zhishifenzi8266/LinHouYu) 进行了极大量的人工重构与精雕细琢。其中包括但不限于：
- 重新分配和修复 UV 映射以解决闪烁问题 (Z-Fighting)。
- 手动调整裙摆外扩角度、呆毛、多层大波浪卷发等 3D 微雕细节。
- 逐像素重绘角色面部、眼睛高光与服饰贴图。

由于包含了显著的人类创造成分与艺术加工，本项目模型享有完整的著作权。
